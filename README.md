# Bataille Corse

Ce projet est un jeu de Bataille Corse réalisé comme projet de fin d’année en Terminale dans la spécialité NSI.
Il date de deux ans, et de nombreuses améliorations sont encore possibles. N’hésitez pas à me faire part de vos conseils ou retours sur le code !

---

J’ai revisité certaines règles à ma manière : elles ne correspondent donc pas entièrement à celles présentées sur la page Wikipédia, et certaines ont été modifiées pour s’adapter au projet.

[Règles officielles de la Bataille Corse](https://fr.wikipedia.org/wiki/Bataille_corse)

---

## Installation
### 1) Pré-requis

Assurez-vous d'avoir installé :
- Python 3.9+
- Le module Pygame

```bash
pip install pygame
```

### 2) Cloner le projet
```bash
git clone https://github.com/Yndral-c/Bataille_Corse
cd Bataille_Corse
```

### 3) Lancer le jeu
Depuis la racine du projet

```bash
python main.py
```
